## 목표

명령을 실행했다는 사실에서 끝내지 않고 오류를 확인해 소스로 이동하고 다시 빌드·테스트하는 흐름을 완성한다. 프로젝트의 여러 테스트 터미널, Git, 실행 결과를 같은 문맥으로 연결한다.

## 구현 계획

### 1. 실행별 로그와 결과

#44의 RunId·log descriptor로 follow/search/filter/최근 결과를 제공한다. terminal viewport를 빌드 원본 로그로 취급하지 않는다. terminal scrollback, 등록 작업 로그, 검색 결과의 수명·크기·보관 정책을 구분한다.

새 로그 도착과 사용자의 scroll 위치를 구분하고 follow 중단/재개를 제공한다. 회전·truncate·삭제·보관 만료·부분 기록·긴 줄을 처리한다. bounded 검색과 취소를 적용하고 결과 잘림을 명시한다. terminal 제어문자를 로그/검색 UI에서 임의 실행하지 않는다.

### 2. Problems 수집과 결과 판정

C++ compiler, Qt moc/uic, 빌드 도구, Python test/traceback의 synthetic fixture에서 진단을 수집한다. RunId/source/generation/file/range/severity/log 위치를 유지한다. 여러 줄 진단·상대 경로·반복 메시지를 정확히 연결하고 지원하지 않는 형식은 원본 로그로 접근한다.

실제 exit code와 parser가 찾은 error를 구분한다. exit 성공이지만 error 진단이 있으면 두 사실을 함께 표시하고, 진단을 못 찾았다고 실행 실패를 성공으로 바꾸지 않는다. 새 run의 문제와 과거 문제는 별개이며 늦은 이벤트가 다른 project/run을 덮지 않는다.

### 3. 경로 해석과 소스 이동

작업 cwd와 등록 source/test roots를 기준으로 경로를 해석한다. 외부 테스트 경로를 전부 차단하지 않되 로그 속 임의 path를 사용자가 승인한 위치로 간주하지 않는다. symlink/root 이동/파일 교체·missing/generated/external 위치를 검사한다.

현재 사용하는 편집기의 검증된 실행 파일과 구조화된 file/line 인자로 이동한다. 새 내장 editor/IDE를 요구하지 않는다. terminal 편집기는 별도 owned terminal 등 기존 작업을 침범하지 않는 방식으로 열고, GUI 편집기 호출은 해당 환경에서 사용자가 명시적으로 설정한 외부 도구 호출로만 취급한다. idk 자체 GUI나 X11 창 생존을 필수로 하지 않는다.

공백/한글/개행·옵션처럼 보이는 파일명·인용 문자·지원하지 않는 line position·편집기 실패를 시험한다. 파일 이동만으로 source 쓰기나 command injection이 발생하지 않게 한다.

### 4. Git·환경·테스트 결과의 정확한 관계

#43의 Git/source generation과 #41 환경 revision 변경 이후 이전 진단/실행 결과를 stale로 설명한다. 현재 Git SHA만으로 빌드 당시 소스 snapshot이나 테스트 바이너리 동일성을 보장하지 않는다.

테스트 terminal의 프로젝트 소속과 특정 빌드 결과물 사용 확인은 분리한다. #44의 명시 artifact 관계가 있을 때만 연결을 표시하고, 수동 terminal 실행은 미확인으로 남긴다. 결과물을 찾아 테스트 폴더에 자동 복사/덮어쓰지 않는다.

### 5. 전체 메뉴와 사용자 흐름

프로젝트 선택→여러 terminal→Git→빌드→오류→소스→테스트→재접속을 최소 메뉴로 연결한다. 화면 이동 때 terminal 상태, Git message draft, 로그 위치, 선택 run을 보존한다. 내부 Session/Target/Operation 용어를 사용자가 모두 배워야만 실행할 수 있는 UI로 만들지 않는다.

좁은 화면, 키보드-only, 한글 입력, 메뉴 키 충돌, focus 복원을 검증한다. 확인은 초기 실행 정의/변경·위험 동작에 집중하고 같은 승인 작업의 일상 실행에는 남발하지 않는다. 알림은 해당 project/run으로 이동하며 비밀 원문을 공통 알림/최근 목록에 복제하지 않는다.
