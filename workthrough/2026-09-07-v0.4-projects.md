# B02 — 프로젝트 연결·환경·터미널 정의

WP02/#41, R01~05/08/15/16의 정의·연결 범위를 구현했다. 프로젝트별 개발 2개와 외부 테스트
3개, 추가 6번째 terminal을 실제 경로·셸 fixture로 다룬다. 재접속과 live 셸 수명은 B03 인계다.

`ProjectService`가 CLI와 TUI의 동일 revision 검사·원자 저장을 담당한다. 안정 UUID, 이름 중복,
루트 이동, 관련 linked worktree, 순서·기본/임시 정의와 source 인수 편집을 지원한다. 연결·편집은
원본 스크립트를 실행하지 않는다. 초기화 신뢰는 실제 셸·정적 startup·HOME·source 내용/인수·
canonical 폴더에 묶이며, 캡처 환경은 bounded memory에만 두고 Debug/JSON에서 값이 노출되지 않는다.
TUI는 검토 전 저장하지 않고 취소·resize·오류 뒤 초안을 보존한다.

검토에서 발견한 기반 결함도 함께 수정했다. FIFO 상태 파일을 비차단으로 거부하고 공유 쓰기 가능
ancestor를 검증한다. 셸 구현 검사만 환경 오염을 제거하며 실제 launch 환경은 보존한다.
터미널 OSC를 16 KiB로 제한하고 oversized 제어 문자열은 종결자까지 버린다. 질의 출력 제한 뒤에도
사용자 Ctrl-C를 보낼 수 있으며 PTY EOF의 synchronized output을 flush한다. Drop은 PTY를 먼저
해제하고 기존 reader worker에서 자식을 회수하여 무기한 대기·zombie·추가 reaper thread를 피한다.

- WSL Ubuntu 26.04.1, Rust 1.97.1, tcsh 6.24.13에서 전체 workspace: 69 PASS, 별도 실제 PTY 4 PASS.
- 실제 BSD csh 20240808과 tcsh 각각 `project_flow` 13/13, `csh_init` 11/11 PASS.
- UI 12개에는 TestBackend 메뉴·초안·신뢰·경로 검증과 실제 PTY의 한글 연결→resize→저장→종료가 포함된다.
- 최초 전체 실행은 로컬 기본 `/usr/bin/tcsh` 미설치로 CLI trust가 실패했다. 준비된 실제 셸의
  `IDK_TEST_SHELL` 경로를 지정한 전체 재실행이 통과했다. 미설치를 skip/PASS로 바꾸지 않았다.

- `cargo fmt --all --check`, 전체 clippy `-D warnings`: PASS.
- 최종 입력 트리 `fbe3cc5247695d9b34fdbbb6f2c6bd273ff7d032bbaa86b793d3dda78e2c04d0`에서
  정적 musl 후보 2,847,496 bytes를 빌드했다. SHA-256은
