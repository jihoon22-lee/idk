# v0.4 착수 전 에이전트 지침 정리

## 변경과 판단

기존 AGENTS의 Python/pyz 전역 규약이 v0.4의 기술 검증 계획과 충돌했다. 기존 코드 유지보수
규약을 보존하면서 새 구현은 WP01 검증·ADR로 결정하도록 적용 범위를 명시했다.
이 작업은 사용자가 별도로 요청한 개발 준비 작업이며 WP01 구현·수용 완료를 뜻하지 않는다.

- `AGENTS.md`: 기존/신규 규약, 자율 진행과 승인 범위, 조건부 위임, PR 묶음·리뷰·증거 기준 정리.
- `docs/plan.md`, `docs/ARCHITECTURE.md`: 기존 Python 구현에 적용되는 문서임을 표시.
- `docs/development.md`: 실제 CI와 일치하는 변경별 검사, 네 단계 수용 증거, 스킬·모델 운영 안내.
- `.agents/skills/idk-change/`, `.agents/skills/idk-acceptance/`: 변경과 수용 감사의 발동 범위를 분리.
- 개인 `web-search` 스킬: 실제 설치 경로 사용, 기본 검색/공식 Docs와 중복되는 발동 조건 축소,
  격리 의존성 환경으로 실행하는 안내. 검색 스크립트 자체와 프로젝트 의존성은 변경하지 않았다.

개인 Codex 설정은 수정하지 않았다. 사용자가 지정한 컨텍스트 윈도우 512000·자동 압축 한계
430000을 유지했고, 기존 모델·reasoning 설정도 유지했다. 전체 설정 파일의 변경 전후 SHA-256
일치만 확인했으며 설정 원문이나 개인 인증 정보는 기록하지 않는다.

- 독립 에이전트의 읽기 전용 결정 시뮬레이션: 아래 5개 요청을 검토했다. 발견된 두 범위

빌드·smoke·실기 검증은 재실행하지 않았다. GitHub 이슈·PR·태그·릴리스는 변경하지 않았다.
