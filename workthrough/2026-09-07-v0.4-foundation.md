# v0.4 B01 — 실제 셸·터미널·네이티브 검증 기반

## 변경과 결정

WP01 #40의 기반을 새 Rust workspace `crates/idk`로 구현했다. 기존 Python 코드와 CI는
유지하며 새 데이터 namespace·schema/revision·Unix IPC·worktree source-use 예약을 정의했다.
Ratatui/Crossterm과 portable-pty/Alacritty terminal core를 채택했고, 이유와 managed csh startup의
정확한 범위·한계는 `docs/adr/0001-native-terminal-foundation.md`에 기록했다.

메인 #38, 명세 #39, WP01~08을 버전 관리 문서로 연결했다. 사용자 지시에 따라 개발·공개 전 검증·
릴리스 뒤 폐쇄망 실기를 수행하도록 원격 이슈 10개와 AGENTS/수용 스킬의 공개 순서를 동기화했다.
기능 요구와 원본·반출 보호는 유지하며 대상 실기는 미실행으로 추적한다.

## 한계와 인계

B01은 기반과 thin UI다. 프로젝트 연결·호스트·Git 작업·등록 run·운영 UI는 후속 B02~B07의 구현이다.
명시적 managed startup의 자동 history/directory-stack 저장 차이, 초기화 hard error의 incomplete
상태, 확인하지 않은 tcsh lf 빌드 조건을 ADR에 기록했다. 전통 csh login의 별도 실행 경로를 실제로
검증했고 caller는 등록 task에도 PreparedShell의 bootstrap bytes를 전달해야 한다.

세션 종료 요청은 실제 exit와 다르다. 후속 호스트는 이를 재확인해야 한다. Git canonical path만으로
동일 경로의 삭제·재생성까지 식별하지 못하므로 B04에서 실행 전후 fingerprint를 추가한다.
패키지 license inventory는 B01 조사 결과이며 공개 전 B06에서 full notice를 완성한다.
폐쇄망 실기는 공개 결과물로 사용자가 후속 수행하며 현재 미실행이다.
